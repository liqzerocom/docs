The LiqZero Core SDK (`@orderly.network/core`) is the foundational library that powers every higher-level SDK in the LiqZero ecosystem. It handles the primitives that every integration must deal with: generating and storing ed25519 trading key pairs, computing account IDs, signing API requests, and interacting with smart contracts. The React Hooks SDK is built on top of the Core SDK — when you use `@orderly.network/hooks`, Core SDK functionality is already included. You only need to install and use the Core SDK directly when you're working outside of React or need to access lower-level APIs.

## When to Use the Core SDK Directly

<CardGroup cols={2}>
  <Card title="Non-React Applications" icon="server">

  </Card>
  <Card title="Server-Side Integrations" icon="database">

## Key Functionality

### LiqZero Key Generation

LiqZero uses ed25519 key pairs as trading keys. Each trading session is authorized by a key pair whose public key is registered against a wallet address on-chain. The Core SDK provides helpers to generate these key pairs, store them, and retrieve them for signing.

```ts
import { generateKeyPair } from "@orderly.network/core";

// Generate a new ed25519 trading key pair
const keyPair = await generateKeyPair();

console.log("Public key:", keyPair.publicKey);
// Register publicKey on-chain via the LiqZero smart contract
```

### Request Signing

All authenticated LiqZero REST API requests require four headers signed with your ed25519 trading key. The Core SDK constructs and signs these headers for you.

```ts
import { createSignature } from "@orderly.network/core";

const timestamp = Date.now();
const method = "GET";
const path = "/v1/positions";
const body = ""; // Empty string for GET requests

const signature = await createSignature({
  secretKey: keyPair.secretKey,
  method,
  path,
  timestamp,
  body,
});

// Attach to your request:
// perpo-account-id: <your account ID>
// perpo-key:        <ed25519:base58-encoded-public-key>
// perpo-timestamp:  <timestamp>
// perpo-signature:  <signature>
```

### Account ID Computation

Your LiqZero account ID is derived from your wallet address and your broker ID. The Core SDK computes this deterministically.

```ts
import { getAccountId } from "@orderly.network/core";

const accountId = getAccountId({
  address: "0xYourWalletAddress",
  brokerId: "your-broker-id",
});

console.log("Account ID:", accountId);
// Use this value in the perpo-account-id header
```

### Key Store Interface

The Core SDK defines a `OrderlyKeyStore` interface that abstracts key persistence. Implement this interface to store keys in any backend — localStorage, a secrets manager, IndexedDB, or a hardware module.

```ts
import type { OrderlyKeyStore } from "@orderly.network/core";

class MySecureKeyStore implements OrderlyKeyStore {
  async getKey(accountId: string): Promise<KeyPair | null> {
    // Retrieve from your secure storage
    const stored = await mySecretsManager.get(`liqzero-key:${accountId}`);
    return stored ? JSON.parse(stored) : null;
  }

  async setKey(accountId: string, keyPair: KeyPair): Promise<void> {
    // Persist to your secure storage
    await mySecretsManager.set(
      `liqzero-key:${accountId}`,
      JSON.stringify(keyPair)
    );
  }

  async cleanKey(accountId: string): Promise<void> {
    await mySecretsManager.delete(`liqzero-key:${accountId}`);
  }
}
```

Pass your implementation into the `OrderlyConfigProvider` when using the Hooks SDK:

```tsx
import { OrderlyConfigProvider } from "@orderly.network/hooks";

<OrderlyConfigProvider
  brokerId="your-broker-id"
  networkId="mainnet"
  keyStore={new MySecureKeyStore()}
>
  {children}
</OrderlyConfigProvider>
```

### Smart Contract Interaction Helpers

The Core SDK provides helpers for constructing the calldata needed to interact with LiqZero's on-chain contracts — including deposit, withdrawal, and PnL settlement transactions.

```ts
import { encodeDepositCalldata } from "@orderly.network/core";

const calldata = encodeDepositCalldata({
  accountId,
  brokerHash,
  tokenHash,
  tokenAmount,
});

// Submit this calldata to the LiqZero Vault contract on your target chain
```

<Tip>
  Contract addresses for all supported chains are listed on the [Smart Contract Addresses](/api-reference/contracts/addresses) page. ABIs are available at [github.com/OrderlyNetwork/contract-evm-abi](https://github.com/OrderlyNetwork/contract-evm-abi).
</Tip>

## Relationship to Other SDKs

The diagram below shows how the Core SDK fits into the broader LiqZero SDK stack:

```
┌─────────────────────────────────────────────────────────┐
│              React Components SDK                        │
│  (@orderly.network/react-app + page packages)            │
├─────────────────────────────────────────────────────────┤
│              React Hooks SDK                             │
│  (@orderly.network/hooks)                                │
├────────────────────────────┬────────────────────────────┤
│        Core SDK            │        Perp SDK             │
│  (@orderly.network/core)   │  (@orderly.network/perp)    │
└────────────────────────────┴────────────────────────────┘
```

- The **React Hooks SDK** depends on both the Core SDK (for signing and key management) and the Perp SDK (for trading calculations).
- The **React Components SDK** depends on the Hooks SDK, and transitively on Core and Perp.
- You can use the **Core SDK standalone** for any non-React or server-side use case.

## Technical Reference

Full TypeScript type definitions, interface documentation, and utility function signatures are shipped with the package. Key modules include:

- `orderly_network_core` — account, key pair, and signing utilities
- `orderly_network_core.utils` — encoding, hashing, and helper functions
