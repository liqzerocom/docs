The LiqZero React Components SDK (`@orderly.network/react-app`) gives you a modular set of pre-built React components for every part of a perpetual futures DEX — trading page, portfolio dashboard, orderbook, order entry, positions panel, and more. The SDK is designed in three layers (UI primitives, block components, and full pages), so you can use a complete trading page out of the box or compose individual blocks into a custom layout. All components support theming through CSS variables, responsive viewports, and i18n.

<Note>
  The React Components SDK is the fastest path to a working DEX frontend. If you need full control over component structure and styling, use the [React Hooks SDK](/sdks/hooks-sdk) instead.
</Note>

## Installation

Install the base UI library and the app provider package together. The `@orderly.network/ui` package contains the core component styles; `@orderly.network/react-app` provides the global provider.

<CodeGroup>
```bash npm
npm install @orderly.network/ui @orderly.network/react-app
```

```bash yarn
yarn add @orderly.network/ui @orderly.network/react-app
```

```bash pnpm
pnpm add @orderly.network/ui @orderly.network/react-app
```
</CodeGroup>

### Import the Stylesheet

Add the following import at the root of your application (e.g., `_app.tsx`, `main.tsx`, or `index.tsx`) so that the component styles are loaded globally:

```tsx
import "@orderly.network/ui/dist/styles.css";
```

## Provider Setup

Wrap your application with `OrderlyAppProvider` to configure your builder identity and network. Replace `"your-broker-id"` with the broker ID you received during [builder onboarding](/introduction/getting-started/what-is-liqzero).

```tsx
import React, { FC, ReactNode } from "react";
import { OrderlyAppProvider } from "@orderly.network/react-app";
import "@orderly.network/ui/dist/styles.css";

const App: FC<{ children: ReactNode }> = ({ children }) => {
  return (
    <OrderlyAppProvider
      brokerId="your-broker-id"
      brokerName="Your DEX Name"
      networkId="mainnet"
      appIcons={{
        main: { img: "/logo.svg" },
        secondary: { img: "/logo-icon.svg" },
      }}
    >
      {children}
    </OrderlyAppProvider>
  );
};

export default App;
```

<ParamField path="brokerId" type="string" required>
  Your unique builder/broker ID registered with LiqZero. Obtain this during the builder onboarding flow.
</ParamField>

<ParamField path="brokerName" type="string" required>
  The display name of your DEX shown in the UI.
</ParamField>

<ParamField path="networkId" type="string" required>
  Set to `"mainnet"` or `"testnet"`. Cannot be changed at runtime without a full page reload.
</ParamField>

<ParamField path="appIcons" type="object">
  Logo assets for the navigation header. Accepts `main` and `secondary` entries, each with an `img` URL.
</ParamField>

## Wallet Connection

The SDK ships with a built-in wallet connector that supports both EVM chains and Solana. Install the connector package, then wrap `OrderlyAppProvider` with `WalletConnectorProvider`.

<Steps>
  <Step title="Install the wallet connector">
    <CodeGroup>
    ```bash npm
    npm install @orderly.network/wallet-connector
    ```

    ```bash yarn
    yarn add @orderly.network/wallet-connector
    ```

    ```bash pnpm
    pnpm add @orderly.network/wallet-connector
    ```
    </CodeGroup>
  </Step>
  <Step title="Wrap your app with WalletConnectorProvider">
    ```tsx
    import { WalletConnectorProvider } from "@orderly.network/wallet-connector";
    import { WalletAdapterNetwork } from "@solana/wallet-adapter-base";
    import { OrderlyAppProvider } from "@orderly.network/react-app";
    import "@orderly.network/ui/dist/styles.css";

    const App: FC<{ children: ReactNode }> = ({ children }) => {
      return (
        <WalletConnectorProvider
          solanaInitial={{ network: WalletAdapterNetwork.Mainnet }}
        >
          <OrderlyAppProvider
            brokerId="your-broker-id"
            brokerName="Your DEX Name"
            networkId="mainnet"
            appIcons=""
          >
            {children}
          </OrderlyAppProvider>
        </WalletConnectorProvider>
      );
    };
    ```

    <Note>
      If you prefer to use a third-party wallet library (e.g., RainbowKit or Wagmi), implement the `WalletConnectorContextState` interface from `@orderly.network/hooks` and pass it as a custom adapter.
    </Note>
  </Step>
</Steps>

## Page Layout and Scaffold

If you want the SDK's built-in top navigation, side navigation bar, and footer, install the scaffold layout package:

<CodeGroup>
```bash npm
npm install @orderly.network/ui-scaffold
```

```bash yarn
yarn add @orderly.network/ui-scaffold
```
</CodeGroup>

Then wrap your page content with the `Scaffold` component:

```tsx
import Scaffold from "@orderly.network/ui-scaffold";

const Layout = ({ children, currentPath, onRouteChange }) => (
  <Scaffold
    mainNavProps={{
      // Configure navigation items as needed
    }}
    footerProps={{}}
    routerAdapter={{
      onRouteChange, // Handles navigation menu click events
      currentPath,
    }}
  >
    {children}
  </Scaffold>
);
```

## Page Components

The SDK provides the following full-page components. Install each package separately, then integrate with your React routing framework.

| Package | Description |
|---|---|
| `@orderly.network/trading` | Full trading page: chart, orderbook, order entry, positions |
| `@orderly.network/portfolio` | Personal portfolio dashboard and history |
| `@orderly.network/markets` | Market list with 24h stats |
| `@orderly.network/referral` | Referral program page |
| `@orderly.network/trading-rewards` | Trading rewards dashboard |
| `@orderly.network/affiliate` | Affiliate program page |

### Next.js Example

```tsx
// app/trade/page.tsx
import TradingPage from "@orderly.network/trading";

export default function TradePage() {
  return <TradingPage symbol="PERP_ETH_USDC" />;
}
```

<Tip>
  Framework-specific starter templates are available for [Next.js](https://github.com/OrderlyNetwork/orderly-js-sdk-nextjs-template) and [Create React App](https://github.com/OrderlyNetwork/orderly-js-sdk-cra-template). Clone one as your starting point to skip boilerplate setup.
</Tip>

## Theming

Customize the look and feel of all components by overriding CSS custom properties. Add your overrides to your global stylesheet or to a `:root` block:

```css
:root {
  /* Brand colors */
  --oui-color-primary: #7c3aed;
  --oui-color-primary-light: #a78bfa;

  /* Background surfaces */
  --oui-color-base-1: #0f0f14;
  --oui-color-base-2: #18181f;
  --oui-color-base-3: #22222c;

  /* Typography */
  --oui-font-family: "Inter", sans-serif;

  /* Trading colors */
  --oui-color-buy: #22c55e;
  --oui-color-sell: #ef4444;
}
```

<Note>
  The full list of available CSS variables is documented in the [Storybook](https://storybook.orderly.network/) under the theming section. You can preview changes live before applying them to your DEX.
</Note>
