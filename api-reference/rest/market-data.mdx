The Market Data API provides all the public information your frontend needs to display markets, populate order entry forms, and render a trade history feed. These endpoints are unauthenticated — no `perpo-*` headers are required — making them safe to call directly from client-side code or CDN-cached proxies.

---

## Get All Symbols

Retrieve metadata for every tradeable symbol available on the LiqZero platform. Use this to populate market selector dropdowns and to validate order parameters before submission.

**`GET /v1/public/info`**

### Example Request

```bash cURL
curl --request GET \
  --url https://api.liqzero.com/v1/public/info
```

### Response

```json
{
  "success": true,
  "data": {
    "rows": [
      {
        "symbol": "PERP_ETH_USDC",
        "quote_min": 0.01,
        "quote_max": 100000.00,
        "base_min": 0.001,
        "base_max": 1000.0,
        "tick_size": 0.01,
        "step_size": 0.001
      },
      {
        "symbol": "PERP_BTC_USDC",
        "quote_min": 1.00,
        "quote_max": 1000000.00,
        "base_min": 0.0001,
        "base_max": 100.0,
        "tick_size": 1.00,
        "step_size": 0.0001
      }
    ]
  },
  "timestamp": 1702989203989
}
```

<ResponseField name="rows[].symbol" type="string">
  The trading pair symbol in `PERP_<TOKEN>_USDC` format.
</ResponseField>

<ResponseField name="rows[].quote_min" type="number">
  Minimum allowed order price in USDC. Submitting an order below this price returns error `-1103`.
</ResponseField>

<ResponseField name="rows[].quote_max" type="number">
  Maximum allowed order price in USDC. Submitting an order above this price returns error `-1103`.
</ResponseField>

<ResponseField name="rows[].base_min" type="number">
  Minimum allowed order quantity in base asset units. Submitting below this returns error `-1104`.
</ResponseField>

<ResponseField name="rows[].base_max" type="number">
  Maximum allowed order quantity in base asset units. Submitting above this returns error `-1104`.
</ResponseField>

<ResponseField name="rows[].tick_size" type="number">
  Price increment. All limit prices must be exact multiples of this value.
</ResponseField>

<ResponseField name="rows[].step_size" type="number">
  Quantity increment. All order quantities must be exact multiples of this value.
</ResponseField>

## Get Symbol Info

Retrieve metadata for a single specific symbol by name.

**`GET /v1/public/info/:symbol`**

### Path Parameters

<ParamField path="symbol" type="string" required>
  The symbol to query, e.g. `PERP_ETH_USDC`.
</ParamField>

### Example Request

```bash cURL
curl --request GET \
  --url https://api.liqzero.com/v1/public/info/PERP_ETH_USDC
```

### Response

```json
{
  "success": true,
  "data": {
    "symbol": "PERP_ETH_USDC",
    "quote_min": 0.01,
    "quote_max": 100000.00,
    "base_min": 0.001,
    "base_max": 1000.0,
    "tick_size": 0.01,
    "step_size": 0.001
  },
  "timestamp": 1702989203989
}
```

<ResponseField name="symbol" type="string">
  The trading pair symbol.
</ResponseField>

<ResponseField name="quote_min" type="number">
  Minimum order price in USDC.
</ResponseField>

<ResponseField name="quote_max" type="number">
  Maximum order price in USDC.
</ResponseField>

<ResponseField name="base_min" type="number">
  Minimum order quantity in base asset units.
</ResponseField>

<ResponseField name="base_max" type="number">
  Maximum order quantity in base asset units.
</ResponseField>

<ResponseField name="tick_size" type="number">
  Minimum price increment. Validate order prices against this before submission to avoid `-1103` errors.
</ResponseField>

<ResponseField name="step_size" type="number">
  Minimum quantity increment. Validate order quantities against this before submission to avoid `-1104` errors.
</ResponseField>

<Tip>
  Cache symbol info locally and refresh it on a schedule (e.g. every 5 minutes). Symbol constraints rarely change, and caching reduces latency on order entry form renders.
</Tip>

## Get Orderbook Snapshot

Retrieve a snapshot of the current order book for a symbol, including the top bid and ask price levels.

**`GET /v1/public/orderbook/:symbol`**

### Path Parameters

<ParamField path="symbol" type="string" required>
  The symbol to query, e.g. `PERP_ETH_USDC`.
</ParamField>

### Example Request

```bash cURL
curl --request GET \
  --url https://api.liqzero.com/v1/public/orderbook/PERP_ETH_USDC
```

### Response

```json
{
  "success": true,
  "data": {
    "symbol": "PERP_ETH_USDC",
    "timestamp": 1702989203000,
    "asks": [
      [2001.50, 1.200],
      [2002.00, 0.500],
      [2003.00, 2.000]
    ],
    "bids": [
      [2000.00, 0.800],
      [1999.50, 1.500],
      [1998.00, 3.000]
    ]
  },
  "timestamp": 1702989203989
}
```

<ResponseField name="asks" type="array">
  Array of ask price levels, each as `[price, quantity]`. Sorted ascending by price (best ask first).
</ResponseField>

<ResponseField name="bids" type="array">
  Array of bid price levels, each as `[price, quantity]`. Sorted descending by price (best bid first).
</ResponseField>

<Note>
  For a live, continuously updated order book, subscribe to the [WebSocket orderbook stream](/api-reference/websocket/public-streams) instead of polling this REST endpoint. The REST snapshot is best used for initial page load hydration.
</Note>

## Get Recent Trades

Retrieve the most recent publicly executed trades for a symbol. Use this to render a live trade feed in your UI.

**`GET /v1/public/trades/:symbol`**

### Path Parameters

<ParamField path="symbol" type="string" required>
  The symbol to query, e.g. `PERP_ETH_USDC`.
</ParamField>

### Query Parameters

<ParamField query="limit" type="number">
  Number of recent trades to return. Maximum is `100`. Defaults to `25`.
</ParamField>

### Example Request

```bash cURL
curl --request GET \
  --url 'https://api.liqzero.com/v1/public/trades/PERP_ETH_USDC?limit=50'
```

### Response

```json
{
  "success": true,
  "data": {
    "rows": [
      {
        "symbol": "PERP_ETH_USDC",
        "side": "BUY",
        "executed_price": 2001.50,
        "executed_quantity": 0.5,
        "executed_timestamp": 1702989200000
      },
      {
        "symbol": "PERP_ETH_USDC",
        "side": "SELL",
        "executed_price": 2000.00,
        "executed_quantity": 1.2,
        "executed_timestamp": 1702989190000
      }
    ]
  },
  "timestamp": 1702989203989
}
```

<ResponseField name="rows[].symbol" type="string">
  Trading pair symbol.
</ResponseField>

<ResponseField name="rows[].side" type="string">
  The aggressor side of the trade: `BUY` (taker was buyer) or `SELL` (taker was seller).
</ResponseField>

<ResponseField name="rows[].executed_price" type="number">
  The price at which the trade was executed, in USDC.
</ResponseField>

<ResponseField name="rows[].executed_quantity" type="number">
  The quantity traded, in base asset units.
</ResponseField>

<ResponseField name="rows[].executed_timestamp" type="integer">
  Trade execution time as a 13-digit Unix timestamp in milliseconds.
</ResponseField>

## Get Builder List

Retrieve the list of registered builders (DEX frontends) that have integrated with LiqZero. This public endpoint requires no authentication.

**`GET /v1/public/broker/name`**

### Query Parameters

<ParamField query="broker_id" type="string">
  If provided, filters the response to return details for a single builder only.
</ParamField>

### Example Request

<CodeGroup>

```bash cURL
curl --request GET \
  --url https://api.liqzero.com/v1/public/broker/name
```

```typescript TypeScript
const response = await fetch('https://api.liqzero.com/v1/public/broker/name');
const { data } = await response.json();
console.log(data.rows);
```

```python Python
import requests
response = requests.get("https://api.liqzero.com/v1/public/broker/name")
print(response.json())
```

</CodeGroup>

### Response

```json
{
  "success": true,
  "data": {
    "rows": [
      {
        "broker_id": "my_builder_id",
        "broker_name": "My Perp DEX"
      }
    ]
  },
  "timestamp": 1702989203989
}
```

<ResponseField name="rows[].broker_id" type="string">
  The unique builder identifier used in registration and order routing.
</ResponseField>

<ResponseField name="rows[].broker_name" type="string">
  The human-readable display name of the builder's platform.
</ResponseField>
