The Orders API is the core of your trading integration. Use it to submit new orders to the shared LiqZero orderbook, cancel pending orders, and retrieve historical and live order state for your users. All three endpoints require [authentication](/api-reference/authentication) — include the four `perpo-*` headers on every request.

---

## Create Order

Submit a new order to the LiqZero perpetual futures orderbook.

**`POST /v1/order`**

<Note>
  For `LIMIT`, `IOC`, `FOK`, and `POST_ONLY` orders you must supply `order_price`. For `MARKET`, `ASK`, and `BID` orders you can supply `order_amount` (quote currency size) instead of `order_quantity`.
</Note>

### Request Parameters

<ParamField body="symbol" type="string" required>
  The trading pair symbol. Must follow the `PERP_<TOKEN>_USDC` format. Example: `PERP_ETH_USDC`.
</ParamField>

<ParamField body="order_type" type="string" required>
  Order execution type. Accepted values: `LIMIT`, `MARKET`, `IOC`, `FOK`, `POST_ONLY`, `ASK`, `BID`.
</ParamField>

<ParamField body="side" type="string" required>
  Order side. Accepted values: `BUY` or `SELL`.
</ParamField>

<ParamField body="order_price" type="number">
  Limit price in USDC. Required for `LIMIT`, `IOC`, `FOK`, and `POST_ONLY` order types. Not required for `MARKET`, `ASK`, or `BID`.
</ParamField>

<ParamField body="order_quantity" type="number">
  Order size in base asset units (e.g. ETH for `PERP_ETH_USDC`). Required for non-market order types.
</ParamField>

<ParamField body="order_amount" type="number">
  Order size expressed in quote currency (USDC). Only applicable for `MARKET`, `ASK`, and `BID` orders. Use this as an alternative to `order_quantity` when you want to spend a fixed USDC amount.
</ParamField>

<ParamField body="client_order_id" type="string">
  Your own identifier for this order, up to 36 characters. Accepts hyphens but the first character must not be a hyphen. Defaults to `null`. Use this for idempotent order placement and easy cross-referencing with your own records.
</ParamField>

<ParamField body="visible_quantity" type="number">
  The portion of the order quantity displayed on the public orderbook (iceberg order). Defaults to the full `order_quantity`. Not supported for `POST_ONLY` orders.
</ParamField>

<ParamField body="reduce_only" type="boolean">
  When `true`, the order can only reduce an existing position and will be rejected if it would open or increase a position. Defaults to `false`.
</ParamField>

<ParamField body="slippage" type="number">
  Maximum acceptable slippage for `MARKET` orders, expressed as a decimal fraction. Orders that would fill beyond this slippage threshold are not executed.
</ParamField>

<ParamField body="post_only_adjust" type="boolean">
  Only applicable for `POST_ONLY` orders. When `true`, LiqZero automatically adjusts the price by one tick toward the current best price to ensure the order posts rather than crosses the spread.
</ParamField>

<ParamField body="margin_mode" type="string">
  Margin mode for the order. Accepted values: `CROSS` or `ISOLATED`. Defaults to the symbol's current default margin mode.
</ParamField>

<ParamField body="order_tag" type="string">
  An optional free-form tag you can attach to the order for your own categorization or analytics.
</ParamField>

### Example Request

<CodeGroup>

```bash cURL
curl --request POST \
  --url https://api.liqzero.com/v1/order \
  --header 'Content-Type: application/json' \
  --header 'perpo-account-id: <your-account-id>' \
  --header 'perpo-key: <your-public-key>' \
  --header 'perpo-signature: <computed-signature>' \
  --header 'perpo-timestamp: 1649920583000' \
  --data '{
    "symbol": "PERP_ETH_USDC",
    "order_type": "LIMIT",
    "side": "BUY",
    "order_quantity": 1.0,
    "order_price": 2000.00,
    "client_order_id": "my-order-001"
  }'
```

```typescript TypeScript
import { signAndSendRequest } from './signer';

const response = await signAndSendRequest(
  '<your-account-id>',
  privateKey,
  'https://api.liqzero.com/v1/order',
  {
    method: 'POST',
    body: JSON.stringify({
      symbol: 'PERP_ETH_USDC',
      order_type: 'LIMIT',
      side: 'BUY',
      order_quantity: 1.0,
      order_price: 2000.00,
      client_order_id: 'my-order-001'
    })
  }
);
const result = await response.json();
console.log(result);
```

```python Python
from signer import Signer
from requests import Request, Session

session = Session()
signer = Signer(account_id, private_key)

req = signer.sign_request(
    Request(
        "POST",
        "https://api.liqzero.com/v1/order",
        json={
            "symbol": "PERP_ETH_USDC",
            "order_type": "LIMIT",
            "side": "BUY",
            "order_quantity": 1.0,
            "order_price": 2000.00,
            "client_order_id": "my-order-001"
        },
    )
)
res = session.send(req)
print(res.json())
```

</CodeGroup>

### Response

```json
{
  "success": true,
  "data": {
    "order_id": 13,
    "client_order_id": "my-order-001",
    "order_type": "LIMIT",
    "order_price": 2000.00,
    "order_quantity": 1.0,
    "error_message": "none"
  },
  "timestamp": 1702989203989
}
```

<ResponseField name="order_id" type="integer">
  LiqZero-assigned order ID. Use this to cancel or query the order.
</ResponseField>

<ResponseField name="client_order_id" type="string">
  Your provided `client_order_id`, echoed back in the response.
</ResponseField>

<ResponseField name="order_type" type="string">
  The order type as accepted by the engine.
</ResponseField>

<ResponseField name="order_price" type="number">
  The price at which the order was submitted.
</ResponseField>

<ResponseField name="order_quantity" type="number">
  The quantity accepted by the engine.
</ResponseField>

<ResponseField name="error_message" type="string">
  `"none"` on success. Contains a description if the order was partially rejected.
</ResponseField>

## Cancel Order

Cancel a pending order by its LiqZero-assigned order ID. The order must be in `NEW` or `PARTIAL_FILLED` status to be cancellable.

**`DELETE /v1/order`**

### Query Parameters

<ParamField query="symbol" type="string" required>
  The symbol the order was placed on, e.g. `PERP_ETH_USDC`.
</ParamField>

<ParamField query="order_id" type="number" required>
  The LiqZero-assigned order ID returned when the order was created.
</ParamField>

### Example Request

<CodeGroup>

```bash cURL
curl --request DELETE \
  --url 'https://api.liqzero.com/v1/order?symbol=PERP_ETH_USDC&order_id=13' \
  --header 'perpo-account-id: <your-account-id>' \
  --header 'perpo-key: <your-public-key>' \
  --header 'perpo-signature: <computed-signature>' \
  --header 'perpo-timestamp: 1649920583000'
```

```typescript TypeScript
const response = await signAndSendRequest(
  '<your-account-id>',
  privateKey,
  'https://api.liqzero.com/v1/order?symbol=PERP_ETH_USDC&order_id=13',
  { method: 'DELETE' }
);
const result = await response.json();
console.log(result);
```

```python Python
req = signer.sign_request(
    Request(
        "DELETE",
        "https://api.liqzero.com/v1/order",
        params={"symbol": "PERP_ETH_USDC", "order_id": 13},
    )
)
res = session.send(req)
print(res.json())
```

</CodeGroup>

### Response

```json
{
  "success": true,
  "data": {
    "status": "CANCEL_SENT"
  },
  "timestamp": 1702989203989
}
```

<ResponseField name="status" type="string">
  Returns `"CANCEL_SENT"` to confirm the cancellation request has been dispatched to the matching engine. The order's final status will transition to `CANCELLED` once confirmed.
</ResponseField>

<Warning>
  Attempting to cancel an order that is already `CANCELLED` or `FILLED` returns error `-1006`. Check the order status with `GET /v1/orders` before cancelling if you are unsure of its current state.
</Warning>

## Get Orders

Retrieve a paginated list of your orders, optionally filtered by symbol, side, type, or status. Use the time range parameters to query historical orders.

**`GET /v1/orders`**

### Query Parameters

<ParamField query="symbol" type="string">
  Filter results to a specific symbol, e.g. `PERP_ETH_USDC`. Omit to return orders across all symbols.
</ParamField>

<ParamField query="side" type="string">
  Filter by order side. Accepted values: `BUY` or `SELL`.
</ParamField>

<ParamField query="order_type" type="string">
  Filter by order type. Accepted values: `LIMIT` or `MARKET`.
</ParamField>

<ParamField query="status" type="string">
  Filter by order status. Accepted values: `NEW`, `CANCELLED`, `PARTIAL_FILLED`, `FILLED`, `REJECTED`, `INCOMPLETE`, `COMPLETED`.
</ParamField>

<ParamField query="start_t" type="number">
  Start of the time range as a 13-digit Unix timestamp in milliseconds.
</ParamField>

<ParamField query="end_t" type="number">
  End of the time range as a 13-digit Unix timestamp in milliseconds.
</ParamField>

<ParamField query="page" type="number">
  Page number to retrieve, starting at `1`. Defaults to `1`.
</ParamField>

<ParamField query="size" type="number">
  Number of records per page. Maximum is `500`. Defaults to `25`.
</ParamField>

<ParamField query="sort_by" type="string">
  Sort order for results. Accepted values: `CREATED_TIME_DESC`, `CREATED_TIME_ASC`, `UPDATED_TIME_DESC`, `UPDATED_TIME_ASC`. Defaults to descending by `created_time` (or `updated_time` when time-range filters are applied).
</ParamField>

<ParamField query="order_tag" type="string">
  Filter by a specific order tag you assigned at creation.
</ParamField>

### Example Request

<CodeGroup>

```bash cURL
curl --request GET \
  --url 'https://api.liqzero.com/v1/orders?symbol=PERP_ETH_USDC&status=FILLED&page=1&size=25' \
  --header 'perpo-account-id: <your-account-id>' \
  --header 'perpo-key: <your-public-key>' \
  --header 'perpo-signature: <computed-signature>' \
  --header 'perpo-timestamp: 1649920583000'
```

```typescript TypeScript
const response = await signAndSendRequest(
  '<your-account-id>',
  privateKey,
  'https://api.liqzero.com/v1/orders?symbol=PERP_ETH_USDC&status=FILLED&page=1&size=25',
  { method: 'GET' }
);
const result = await response.json();
console.log(result.data.rows);
```

```python Python
req = signer.sign_request(
    Request(
        "GET",
        "https://api.liqzero.com/v1/orders",
        params={
            "symbol": "PERP_ETH_USDC",
            "status": "FILLED",
            "page": 1,
            "size": 25
        },
    )
)
res = session.send(req)
print(res.json())
```

</CodeGroup>


<ResponseField name="meta.total" type="integer">
  Total number of orders matching the query filters across all pages.
</ResponseField>

<ResponseField name="meta.records_per_page" type="integer">
  The page size used for this response.
</ResponseField>

<ResponseField name="meta.current_page" type="integer">
  The current page number returned.
</ResponseField>

<ResponseField name="rows[].order_id" type="integer">
  LiqZero-assigned unique order ID.
</ResponseField>

<ResponseField name="rows[].symbol" type="string">
  The trading pair symbol, e.g. `PERP_ETH_USDC`.
</ResponseField>

<ResponseField name="rows[].side" type="string">
  Order side: `BUY` or `SELL`.
</ResponseField>

<ResponseField name="rows[].type" type="string">
  Order type as accepted by the engine.
</ResponseField>

<ResponseField name="rows[].status" type="string">
  Current order status: `NEW`, `PARTIAL_FILLED`, `FILLED`, `CANCELLED`, `REJECTED`, `INCOMPLETE`, or `COMPLETED`.
</ResponseField>

<ResponseField name="rows[].price" type="number">
  Order limit price in USDC.
</ResponseField>

<ResponseField name="rows[].quantity" type="number">
  Original order quantity in base asset units.
</ResponseField>

<ResponseField name="rows[].total_executed_quantity" type="number">
  Total quantity filled so far.
</ResponseField>

<ResponseField name="rows[].average_executed_price" type="number">
  Volume-weighted average fill price.
</ResponseField>

<ResponseField name="rows[].total_fee" type="number">
  Total trading fee charged for this order.
</ResponseField>

<ResponseField name="rows[].realized_pnl" type="number">
  Realized profit and loss from this order, in USDC.
</ResponseField>

<ResponseField name="rows[].margin_mode" type="string">
  Margin mode under which the order was placed: `CROSS` or `ISOLATED`.
</ResponseField>

<ResponseField name="rows[].created_time" type="integer">
  Order creation time as a 13-digit Unix timestamp in milliseconds.
</ResponseField>

<ResponseField name="rows[].updated_time" type="integer">
  Last status update time as a 13-digit Unix timestamp in milliseconds.
</ResponseField>

<Tip>
  For real-time order status updates without polling, subscribe to the [WebSocket execution report stream](/api-reference/websocket/private-streams). The `executionreport` topic fires instantly on every order state transition — placement, partial fill, fill, and cancellation.
</Tip>
