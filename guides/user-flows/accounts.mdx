Every user who trades through your LiqZero-powered DEX needs a registered account on the network. Accounts are scoped per wallet per builder — a single wallet can hold one account for each builder integration, and those accounts are fully independent of one another. This page walks you through computing the deterministic account ID, checking whether a wallet is already registered, and completing the full on-chain registration flow.

## Account Structure

LiqZero ties each account to a specific `(walletAddress, brokerId)` pair. Because accounts are not interlinked across builders, a user's balance, positions, and trading history on your platform are completely isolated from any other builder using LiqZero. This means you can safely offer your own branded experience without risk of cross-contamination of user state.

### Account ID

Every account is uniquely identified by an `accountId` computed deterministically from the wallet address and the builder ID. The four-step derivation is:

1. Convert the wallet address to bytes.
2. Compute the `keccak256` hash of the `brokerId` string and convert to bytes.
3. ABI-encode the two byte values together.
4. Take the `keccak256` hash of the encoded result and convert back to a hex string.

```typescript
export function getAccountId(userAddress: string, brokerId: string): string {
  const abicoder = AbiCoder.defaultAbiCoder();
  return keccak256(
    abicoder.encode(
      ['address', 'bytes32'],
      [userAddress, solidityPackedKeccak256(['string'], [brokerId])]
    )
  );
}
```

<Tip>
  Compute the `accountId` client-side whenever you need it — there is no API call required. The result is always identical for the same wallet and builder combination.
</Tip>

## Account Registration

Before a user can deposit funds or place orders, their wallet must be registered on LiqZero. Follow the steps below — the process requires one API call for a nonce, one EIP-712 signature from the user's wallet, and one POST to complete registration.

<Steps>
  <Step title="Choose a valid chain and builder">
    Registration is chain-specific. Select a chain from the [supported chains list](/api-reference/contracts/addresses) and confirm your `brokerId` is active. You can also query the full list of registered builders via the **Get Builder List** public API.
  </Step>

  <Step title="Check if the wallet is already registered">
    Avoid duplicate registration errors by checking first. Use the **Check Wallet Registration** or **Check Account Exists** public API endpoints.

    <CodeGroup>
      ```java Java
      String baseUrl = "https://testnet-api.liqzero.com";

      OkHttpClient client = new OkHttpClient();

      // Replace with the actual wallet address
      String walletAddress = "0xYourWalletAddress";

      Request checkReq = new Request.Builder()
            .url(baseUrl + "/v1/get_account?address=" + walletAddress + "&broker_id=your_broker_id")
            .build();
      String checkRes;
      try (Response response = client.newCall(checkReq).execute()) {
          checkRes = response.body().string();
      }
      JSONObject checkObj = new JSONObject(checkRes);
      boolean isRegistered = checkObj.getJSONObject("data").getBoolean("account_id") != null;
      ```

      ```python Python
      import requests, json

      base_url = "https://testnet-api.liqzero.com"

      wallet_address = "0xYourWalletAddress"
      broker_id = "your_broker_id"

      res = requests.get(
          f"{base_url}/v1/get_account",
          params={"address": wallet_address, "broker_id": broker_id}
      )
      response = json.loads(res.text)
      is_registered = response.get("data", {}).get("account_id") is not None
      print("Already registered:", is_registered)
      ```

      ```typescript TypeScript
      const BASE_URL = "https://testnet-api.liqzero.com";

      const walletAddress = "0xYourWalletAddress";
      const brokerId = "your_broker_id";

      const checkRes = await fetch(
        `${BASE_URL}/v1/get_account?address=${walletAddress}&broker_id=${brokerId}`
      );
      const checkJson = await checkRes.json();
      const isRegistered = checkJson.data?.account_id != null;
      console.log("Already registered:", isRegistered);
      ```
    </CodeGroup>
  </Step>

  <Step title="Obtain a registration nonce">
    Fetch a one-time nonce from the **Get Registration Nonce** endpoint. This nonce is embedded in the EIP-712 message to prevent replay attacks.

    <CodeGroup>
      ```java Java
      String baseUrl = "https://testnet-api.liqzero.com";

      OkHttpClient client = new OkHttpClient();

      Request nonceReq = new Request.Builder()
            .url(baseUrl + "/v1/registration_nonce")
            .build();
      String nonceRes;
      try (Response response = client.newCall(nonceReq).execute()) {
          nonceRes = response.body().string();
      }
      JSONObject nonceObj = new JSONObject(nonceRes);

      String registrationNonce = nonceObj.getJSONObject("data").getString("registration_nonce");
      ```

      ```python Python
      import requests, json

      base_url = "https://testnet-api.liqzero.com"

      res = requests.get(f"{base_url}/v1/registration_nonce")
      response = json.loads(res.text)
      registration_nonce = response["data"]["registration_nonce"]
      ```

      ```typescript TypeScript
      const BASE_URL = "https://testnet-api.liqzero.com";

      const nonceRes = await fetch(`${BASE_URL}/v1/registration_nonce`);
      const nonceJson = await nonceRes.json();
      const registrationNonce = nonceJson.data.registration_nonce as string;
      ```
    </CodeGroup>
  </Step>

  <Step title="Sign the registration message via EIP-712">
    Build and sign the `Registration` message from the user's wallet. The domain is processed entirely off-chain, so the `verifyingContract` is set to the canonical zero-equivalent address.

    The message payload must contain the following fields:

    | Name | Type | Required | Description |
    |---|---|---|---|
    | `brokerId` | string | Y | Your builder ID |
    | `chainId` | int | Y | Chain ID of the registering chain |
    | `timestamp` | timestamp | Y | Current time in UNIX milliseconds |
    | `registrationNonce` | string | Y | Nonce obtained in the previous step |

    Example message:
    ```json
    {
      "brokerId": "your_broker_id",
      "chainId": 42161,
      "timestamp": 1685973017064,
      "registrationNonce": "194528949540"
    }
    ```

  <Step title="Register the account via POST /v1/register_account">
    Submit the signed message, signature, and user's wallet address to complete registration. The response returns the new `account_id`.

    <CodeGroup>
      ```java Java
      String baseUrl = "https://testnet-api.liqzero.com";

      JSONObject jsonBody = new JSONObject();
      jsonBody.put("message", registerMessage);
      jsonBody.put("signature", signatureToHashString(signature));
      jsonBody.put("userAddress", credentials.getAddress());

      RequestBody body = RequestBody.create(jsonBody.toString(), MediaType.get("application/json"));
      Request registerReq = new Request.Builder()
            .url(baseUrl + "/v1/register_account")
            .post(body)
            .build();
      String registerRes;
      try (Response response = client.newCall(registerReq).execute()) {
          registerRes = response.body().string();
      }
      JSONObject registerObj = new JSONObject(registerRes);

      String accountId = registerObj.getJSONObject("data").getString("account_id");
      System.out.println("accountId: " + accountId);

      // Helper: convert signature bytes to hex string
      public static String signatureToHashString(Sign.SignatureData signature) {
          byte[] retval = new byte[65];
          System.arraycopy(signature.getR(), 0, retval, 0, 32);
          System.arraycopy(signature.getS(), 0, retval, 32, 32);
          System.arraycopy(signature.getV(), 0, retval, 64, 1);
          return Numeric.toHexString(retval);
      }
      ```

## Full Registration Example

The snippets below combine all five steps — nonce fetch, EIP-712 signing, and account registration — into a single runnable script.

<CodeGroup>
  ```java Java
  import java.time.Instant;

  import org.apache.commons.codec.binary.Hex;
  import org.json.JSONObject;
  import org.web3j.crypto.*;
  import org.web3j.utils.Numeric;

  import io.github.cdimascio.dotenv.Dotenv;
  import okhttp3.*;

  public class RegisterExample {
      public static JSONObject MESSAGE_TYPES = new JSONObject("""
          {
            "EIP712Domain": [
              {"name": "name", "type": "string"},
              {"name": "version", "type": "string"},
              {"name": "chainId", "type": "uint256"},
              {"name": "verifyingContract", "type": "address"}
            ],
            "Registration": [
              {"name": "brokerId", "type": "string"},
              {"name": "chainId", "type": "uint256"},
              {"name": "timestamp", "type": "uint64"},
              {"name": "registrationNonce", "type": "uint256"}
            ]
          }""");

      public static JSONObject OFF_CHAIN_DOMAIN = new JSONObject("""
          {
            "name": "Orderly",
            "version": "1",
            "chainId": 42161,
            "verifyingContract": "0xCcCCccccCCCCcCCCCCCcCcCccCcCCCcCcccccccC"
          }""");

      public static void main(String[] args) throws Exception {
          String baseUrl = "https://testnet-api.liqzero.com";
          String brokerId = "your_broker_id";
          int chainId = 42161;

          Dotenv dotenv = Dotenv.load();
          String pk = dotenv.get("PRIVATE_KEY");
          Credentials credentials = Credentials.create(ECKeyPair.create(Hex.decodeHex(pk)));
          OkHttpClient client = new OkHttpClient();

          Request nonceReq = new Request.Builder()
                .url(baseUrl + "/v1/registration_nonce")
                .build();
          String nonceRes;
          try (Response response = client.newCall(nonceReq).execute()) {
              nonceRes = response.body().string();
          }
          String registrationNonce = new JSONObject(nonceRes)
              .getJSONObject("data").getString("registration_nonce");

          JSONObject registerMessage = new JSONObject();
          registerMessage.put("brokerId", brokerId);
          registerMessage.put("chainId", chainId);
          registerMessage.put("timestamp", Instant.now().toEpochMilli());
          registerMessage.put("registrationNonce", registrationNonce);

          JSONObject typedData = new JSONObject();
          typedData.put("types", MESSAGE_TYPES);
          typedData.put("primaryType", "Registration");
          typedData.put("domain", OFF_CHAIN_DOMAIN);
          typedData.put("message", registerMessage);

          Sign.SignatureData signature = Sign.signTypedData(typedData.toString(), credentials.getEcKeyPair());

          JSONObject jsonBody = new JSONObject();
          jsonBody.put("message", registerMessage);
          jsonBody.put("signature", signatureToHashString(signature));
          jsonBody.put("userAddress", credentials.getAddress());

          RequestBody body = RequestBody.create(jsonBody.toString(), MediaType.get("application/json"));
          Request registerReq = new Request.Builder()
                .url(baseUrl + "/v1/register_account")
                .post(body)
                .build();
          String registerRes;
          try (Response response = client.newCall(registerReq).execute()) {
              registerRes = response.body().string();
          }
          String accountId = new JSONObject(registerRes)
              .getJSONObject("data").getString("account_id");
          System.out.println("accountId: " + accountId);
      }

      public static String signatureToHashString(Sign.SignatureData signature) {
          byte[] retval = new byte[65];
          System.arraycopy(signature.getR(), 0, retval, 0, 32);
          System.arraycopy(signature.getS(), 0, retval, 32, 32);
          System.arraycopy(signature.getV(), 0, retval, 64, 1);
          return Numeric.toHexString(retval);
      }
  }
  ```
