---
title: 'Transfer Funds Between Accounts on LiqZero'
sidebarTitle: 'Internal Transfer'
description: 'Move USDC instantly between LiqZero accounts within your platform — no on-chain transaction, no gas fees, and no block confirmation delay.'
---

Internal transfers let you move USDC between any two LiqZero accounts entirely off-chain. Because the transfer is processed within LiqZero's settlement layer rather than on a public blockchain, it settles instantly with no gas cost and no waiting for block confirmations. This makes internal transfers the right mechanism for sub-account funding, user-to-user payments within your platform, and programmatic balance rebalancing across a portfolio of managed accounts.

The transfer is authorized via an EIP-712 wallet signature from the sender's wallet — the same signing pattern used for deposits and withdrawals. Both the source and destination accounts must be registered on LiqZero. The receiver's account does not need to take any action.

<Note>
  Both the sender and receiver accounts must be registered under the **same builder ID** on LiqZero. Cross-builder internal transfers are not permitted.
</Note>

## Transfer Flow

<Steps>
  <Step title="Obtain a Transfer Nonce">
    Fetch a single-use nonce that will be embedded in the EIP-712 signature to prevent replay attacks. This endpoint requires standard LiqZero authentication headers (`perpo-account-id`, `perpo-key`, `perpo-signature`, `perpo-timestamp`).

    **`GET /v1/transfer_nonce`**

    ```json Response
    {
      "success": true,
      "timestamp": 1712003000000,
      "data": {
        "transfer_nonce": 4
      }
    }
    ```

    <Warning>
      Each nonce is valid for a single request only. Fetch a fresh nonce for every transfer — never reuse a nonce or the signature verification will fail.
    </Warning>
  </Step>

  <Step title="Sign the EIP-712 Transfer Message">
    Construct and sign an EIP-712 `InternalTransfer` message using the nonce from Step 1 and the on-chain domain for the connected chain. The `verifyingContract` must be the LiqZero Ledger contract address for the chain you are connected to (see [Contract Addresses](/api-reference/contracts/addresses)).

    The EIP-712 message type is:

    ```json InternalTransfer Type Definition
    "InternalTransfer": [
      { "name": "receiver", "type": "bytes32" },
      { "name": "token",    "type": "string"  },
      { "name": "amount",   "type": "uint256" },
      { "name": "transferNonce", "type": "uint64" }
    ]
    ```

    | Field | Type | Required | Description |
    |---|---|---|---|
    | `receiver` | bytes32 | Yes | The LiqZero Account ID of the recipient, zero-padded to 32 bytes for signing |
    | `token` | string | Yes | Token to transfer — currently `USDC` |
    | `amount` | uint256 | Yes | Raw amount with decimals (e.g., `1000000` = 1 USDC with 6 decimals) |
    | `transferNonce` | uint64 | Yes | Nonce obtained in Step 1 |

    <Note>
      In the EIP-712 signature, `receiver` must be a `bytes32` value (zero-padded). In the subsequent API request body, pass it as a hex string with the `0x` prefix. Your signing library handles the padding automatically when you pass the hex string.
    </Note>
  </Step>

  <Step title="Submit the Transfer Request">
    POST the signed message to the internal transfer endpoint. Include the EIP-712 signature, the original message parameters, and the sender's wallet address. Standard LiqZero authentication headers are also required on this call.

    **`POST /v2/internal_transfer`**

    ```json Request Body
    {
      "message": {
        "receiver": "0x9ff99a5d6cb71a3ef897b0fff5f5801af6dc5f72d8f1608e61409b8fc965bd68",
        "token": "USDC",
        "amount": "1000000",
        "transferNonce": "4",
        "chainId": "42161",
        "chainType": "EVM"
      },
      "signature": "0xa9f5ef503a95af0bb0211858e8b6a83a3d23d7a84b8db3c2aa3327deb34b084577758cc6d8cbc9a047d60436c62d0591ee6693f34487bea785247608516360991b",
      "userAddress": "0xb6309c90b5ecc2f8a87987294af03951e80bfef0",
      "verifyingContract": "0x6F7a338F2aA472838dEFD3283eB360d4Dff5D203"
    }
    ```

    | Parameter | Type | Required | Description |
    |---|---|---|---|
    | `message.receiver` | string | Yes | Recipient's LiqZero Account ID (hex, `0x`-prefixed) |
    | `message.token` | string | Yes | Token symbol — `USDC` |
    | `message.amount` | string | Yes | Transfer amount in raw units (6 decimal places for USDC) |
    | `message.transferNonce` | string | Yes | Must match the nonce used to produce the signature |
    | `message.chainId` | string | Yes | Chain ID as a string (e.g., `"42161"` for Arbitrum) |
    | `message.chainType` | string | Yes | `EVM` for all EVM-compatible chains; `SOL` for Solana |
    | `signature` | string | Yes | The EIP-712 hex signature |
    | `userAddress` | string | Yes | Sender's wallet address; must match the signing key |
    | `verifyingContract` | string | Yes | Ledger contract address used in the EIP-712 domain |

    ```json Response
    {
      "success": true,
      "timestamp": 1712003100000,
      "data": {
        "id": "transfer-00482910"
      }
    }
    ```

    A `success: true` response confirms the transfer completed. Because internal transfers are processed synchronously within LiqZero's settlement layer, the receiver's balance is updated immediately — no polling required.
  </Step>
</Steps>

## Full Code Example

The example below covers the complete flow: fetching a nonce, signing the EIP-712 message, and submitting the transfer.

<CodeGroup>
```typescript TypeScript
import { ethers } from "ethers";

// ─── Configuration ───────────────────────────────────────────────────────────
const ENV = "mainnet"; // or "testnet"
const ACCOUNT_ID = "0xYOUR_ACCOUNT_ID";
const LIQZERO_KEY = "ed25519:YOUR_PUBLIC_KEY";
const LIQZERO_SECRET = "YOUR_SECRET_HEX";
const WALLET_PRIVATE_KEY = "0xYOUR_WALLET_PRIVATE_KEY";
const USER_ADDRESS = "0xYOUR_WALLET_ADDRESS";
const RECEIVER_ACCOUNT_ID = "0xRECEIVER_ACCOUNT_ID";
const TRANSFER_AMOUNT = 1_000_000; // 1 USDC (6 decimals)

const CHAIN_ID = ENV === "mainnet" ? 42161 : 421614;
const LEDGER_CONTRACT =
  ENV === "mainnet"
    ? "0x6F7a338F2aA472838dEFD3283eB360d4Dff5D203"
    : "0x8794E7260517B1766fc7b55cAfcd56e6bf08600e";
const BASE_URL =
  ENV === "mainnet"
    ? "https://api.liqzero.com"
    : "https://testnet-api.liqzero.com";

// ─── Step 1: Fetch a transfer nonce ──────────────────────────────────────────
async function getTransferNonce(): Promise<number> {
  const path = "/v1/transfer_nonce";
  const timestamp = Date.now().toString();
  // Build auth headers using your ed25519 Trading Key (see API Authentication docs)
  const headers = buildAuthHeaders("GET", path, "", timestamp);

  const res = await fetch(`${BASE_URL}${path}`, { headers });
  const json = await res.json();
  return json.data.transfer_nonce as number;
}

// ─── Step 2: Sign the EIP-712 message ────────────────────────────────────────
async function signTransfer(transferNonce: number): Promise<string> {
  const domain = {
    name: "LiqZero",
    version: "1",
    chainId: CHAIN_ID,
    verifyingContract: LEDGER_CONTRACT,
  };

  const types = {
    InternalTransfer: [
      { name: "receiver",      type: "bytes32" },
      { name: "token",         type: "string"  },
      { name: "amount",        type: "uint256" },
      { name: "transferNonce", type: "uint64"  },
    ],
  };

  // ethers.js zero-pads hex strings to bytes32 automatically
  const receiverBytes32 = ethers.zeroPadValue(RECEIVER_ACCOUNT_ID, 32);

  const message = {
    receiver: receiverBytes32,
    token: "USDC",
    amount: BigInt(TRANSFER_AMOUNT),
    transferNonce: transferNonce,
  };

  const wallet = new ethers.Wallet(WALLET_PRIVATE_KEY);
  return wallet.signTypedData(domain, types, message);
}

// ─── Step 3: Submit the transfer ─────────────────────────────────────────────
async function submitTransfer(
  transferNonce: number,
  signature: string
): Promise<void> {
  const path = "/v2/internal_transfer";
  const timestamp = Date.now().toString();

  const body = JSON.stringify({
    message: {
      receiver: RECEIVER_ACCOUNT_ID,
      token: "USDC",
      amount: String(TRANSFER_AMOUNT),
      transferNonce: String(transferNonce),
      chainId: String(CHAIN_ID),
      chainType: "EVM",
    },
    signature,
    userAddress: USER_ADDRESS,
    verifyingContract: LEDGER_CONTRACT,
  });

  const headers = {
    "Content-Type": "application/json",
    ...buildAuthHeaders("POST", path, body, timestamp),
  };

  const res = await fetch(`${BASE_URL}${path}`, {
    method: "POST",
    headers,
    body,
  });

  const result = await res.json();
  console.log("Transfer result:", result);
}

// ─── Orchestrate ─────────────────────────────────────────────────────────────
async function runInternalTransfer() {
  const nonce = await getTransferNonce();
  const signature = await signTransfer(nonce);
  await submitTransfer(nonce, signature);
}

runInternalTransfer();

// ─── Helpers (see API Authentication docs for full implementation) ────────────
function buildAuthHeaders(
  method: string,
  path: string,
  body: string,
  timestamp: string
): Record<string, string> {
  // Implement ed25519 signing per the API Authentication guide
  const signature = "/* sign `${timestamp}${method}${path}${body}` with your Trading Key */";
  return {
    "perpo-account-id": ACCOUNT_ID,
    "perpo-key": LIQZERO_KEY,
    "perpo-signature": signature,
    "perpo-timestamp": timestamp,
  };
}
```

```python Python
import os
import time
from eth_account import Account
from eth_account.messages import encode_typed_data

# ─── Configuration ────────────────────────────────────────────────────────────
ENV = "mainnet"  # or "testnet"
ACCOUNT_ID = "0xYOUR_ACCOUNT_ID"
LIQZERO_KEY = "ed25519:YOUR_PUBLIC_KEY"
LIQZERO_SECRET = "YOUR_SECRET_HEX"
WALLET_PRIVATE_KEY = os.environ["WALLET_PRIVATE_KEY"]
USER_ADDRESS = "0xYOUR_WALLET_ADDRESS"
RECEIVER_ACCOUNT_ID = "0xRECEIVER_ACCOUNT_ID"
TRANSFER_AMOUNT = 1_000_000  # 1 USDC (6 decimals)

CHAIN_ID = 42161 if ENV == "mainnet" else 421614
LEDGER_CONTRACT = (
    "0x6F7a338F2aA472838dEFD3283eB360d4Dff5D203"
    if ENV == "mainnet"
    else "0x8794E7260517B1766fc7b55cAfcd56e6bf08600e"
)
BASE_URL = (
    "https://api.liqzero.com"
    if ENV == "mainnet"
    else "https://testnet-api.liqzero.com"
)


def sign_internal_transfer(transfer_nonce: int) -> str:
    receiver_hex = (
        RECEIVER_ACCOUNT_ID[2:]
        if RECEIVER_ACCOUNT_ID.startswith("0x")
        else RECEIVER_ACCOUNT_ID
    )
    receiver_bytes = bytes.fromhex(receiver_hex)

    data = {
        "types": {
            "EIP712Domain": [
                {"name": "name",              "type": "string"},
                {"name": "version",           "type": "string"},
                {"name": "chainId",           "type": "uint256"},
                {"name": "verifyingContract", "type": "address"},
            ],
            "InternalTransfer": [
                {"name": "receiver",      "type": "bytes32"},
                {"name": "token",         "type": "string"},
                {"name": "amount",        "type": "uint256"},
                {"name": "transferNonce", "type": "uint64"},
            ],
        },
        "domain": {
            "name": "LiqZero",
            "version": "1",
            "chainId": CHAIN_ID,
            "verifyingContract": LEDGER_CONTRACT,
        },
        "primaryType": "InternalTransfer",
        "message": {
            "receiver":      receiver_bytes,
            "token":         "USDC",
            "amount":        TRANSFER_AMOUNT,
            "transferNonce": transfer_nonce,
        },
    }

    account = Account.from_key(WALLET_PRIVATE_KEY)
    signable = encode_typed_data(full_message=data)
    signed = account.sign_message(signable)
    return signed.signature.hex()
```

## Request & Response Reference

<Accordion title="POST /v2/internal_transfer — Full Field Reference">

**Request Body**

<ParamField body="message.receiver" type="string" required>
  LiqZero Account ID of the recipient. Pass as a hex string with `0x` prefix. Must be zero-padded to 32 bytes in the EIP-712 signature but is a plain hex string here.
</ParamField>
<ParamField body="message.token" type="string" required>
  Token to transfer. Currently only `USDC` is supported.
</ParamField>
<ParamField body="message.amount" type="string" required>
  Transfer amount in raw token units. For USDC (6 decimals), `"1000000"` equals 1 USDC.
</ParamField>
<ParamField body="message.transferNonce" type="string" required>
  Single-use nonce from `GET /v1/transfer_nonce`. Must exactly match the nonce used when producing `signature`.
</ParamField>
<ParamField body="message.chainId" type="string" required>
  Chain ID as a decimal string (e.g., `"42161"` for Arbitrum One).
</ParamField>
<ParamField body="message.chainType" type="string" required>
  `EVM` for all EVM-compatible chains (Arbitrum, Optimism, Base, etc.) or `SOL` for Solana.
</ParamField>
<ParamField body="signature" type="string" required>
  The hex-encoded EIP-712 signature produced in Step 2.
</ParamField>
<ParamField body="userAddress" type="string" required>
  Sender's wallet address. For EVM chains: `0x`-prefixed hex. For Solana: base58 address. Must be the wallet that signed the message.
</ParamField>
<ParamField body="verifyingContract" type="string" required>
  LiqZero Ledger contract address used in the EIP-712 domain. Must match the on-chain deployment for `chainId`.
</ParamField>

**Response**

<ResponseField name="success" type="boolean">
  `true` when the transfer completed successfully
</ResponseField>
<ResponseField name="data.id" type="string">
  Unique transfer ID for record-keeping and support queries
</ResponseField>
<ResponseField name="timestamp" type="number">
  Response timestamp in UNIX milliseconds
</ResponseField>

</Accordion>
